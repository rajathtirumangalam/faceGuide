# FaceGuide

FaceGuide is an accessibility-focused NVDA add-on that helps blind and low vision users independently frame selfies using real-time face positioning, lighting analysis, smile detection, and automatic capture.

## Features

- Real-time face positioning guidance
- Clock-direction orientation feedback
- Distance guidance
- Lighting analysis
- Blur detection
- Smile detection
- Automatic selfie capture
- Hands-free operation
- Works offline

## Gestures

| Gesture | Action |
|---|---|
| NVDA+Shift+G | Start or stop FaceGuide |
| NVDA+Shift+C | Toggle smart selfie mode |

## Requirements

- NVDA 2024.1 or later
- Windows 10 or later
- Webcam

No separate Python installation required.

## Installation

1. Download the latest `.nvda-addon` release
2. Open the file
3. Confirm installation in NVDA
4. Restart NVDA

## Privacy

FaceGuide processes all camera data locally on-device.

- No cloud processing
- No facial recognition
- No internet upload
- No image analytics collection
- No user tracking

Captured images are saved only to the local Pictures folder.

## Known Limitations

- Smile detection accuracy may vary by lighting and webcam quality
- Continuous camera processing may increase CPU usage on older systems
- Multiple faces are not fully supported yet

## Project Goals

FaceGuide explores how computer vision can improve independent camera use for blind users inside screen reader environments.
